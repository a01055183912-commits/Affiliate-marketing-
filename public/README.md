# 제휴 마케팅 실습 도우미 (3-6)

롯데 LIFT 유통·리테일 과정 「3-6. 제휴 마케팅 운영」 실습 ①~⑧을 스스로 생각하고 계산하며 완성하는 웹앱입니다.
내용은 첨부된 **교안(PPTX)** 과 **강사용 해설집(PPTX)** 에 있는 것만 사용했습니다. 교육용으로 구성한 가상 자료입니다.

## 설계 원칙
- **내 생각 먼저**: 칸마다 내 말로 먼저 쓰고, 5자 이상 쓰면 **예시답안(교안판 · 해설집판)** 과 비교할 수 있습니다. 실습의 필수 칸을 모두 채우면 통째 비교도 열립니다.
- **정답은 하나가 아님**: 두 예시답안은 숫자와 선택이 다릅니다(점수, 예산 3억 vs 3.8억, 방문자 7만 vs 8만 등). 판단 기준은 예산(4억)·일정(6주) 안에서 근거가 남아 있는가입니다.
- **원리 이해**: 실습마다 "왜 이렇게 하나요?" 패널(교안·해설집의 설명), 칸별 원리 힌트, 식과 함께 보이는 계산기.
- **계산은 직접**: "내 계산 확인"으로 먼저 계산해 보고, 틀리면 단계별 힌트(단위 → 식 → 값)를 받습니다.
- **자문**: 조건에 걸리면 자문 카드가 뜨고, "막혔어요"는 정답 대신 되묻는 질문을 줍니다. 해설집의 "흔한 오답", "채점 기준", "강사 질문"에서 도출했습니다.
- 앞 실습의 숫자가 뒤로 이어지고(②→④ 파트너 비용, ⑤→⑦ 정량 목표), 넘어갈 때 앞뒤 숫자를 점검합니다.
- 내려받기: 인쇄(PDF, A4 가로) / CSV / 이어하기 JSON.
- 강사용: 헤더의 "예시답안 바로 열기"를 켜면 잠금이 풀리고 예시를 내 워크시트에 불러올 수 있습니다.

## 실행
    npm start        # http://localhost:3000

의존성 없는 Node 정적 서버(`server.js`)와 `public/` 폴더로 구성됩니다.

## Railway 배포
1. Railway → New Project → Deploy from GitHub repo → 이 저장소 선택
2. 배포할 브랜치 지정 (빌드: Nixpacks 자동, 시작: `node server.js`, 헬스체크: `/healthz`)
3. Settings → Networking → Generate Domain
